# 🖥️ PPTX to PDF Converter (Python + Tkinter)

> 🎯 A simple, beginner-friendly tool to convert multiple PowerPoint files (.pptx) into PDF format — with just a few clicks!

This tool lets you **select up to 10 PowerPoint presentations at once**, and automatically converts them to high-quality PDF files using **Microsoft PowerPoint (COM automation)**.  
It features a **clean Tkinter-based UI**, easy setup, and clear progress indication — perfect for students, beginners, and anyone who wants to automate PowerPoint-to-PDF conversion.

---

## 🌟 Features

- 🖱️ Simple and clean graphical interface (Tkinter)
- 📂 Select up to **10 `.pptx` files** at once
- 📤 Choose your own output folder
- ⚡ Converts automatically using Microsoft PowerPoint
- ✅ Progress bar and success messages
- 🪶 Lightweight and beginner-friendly Python project

---

## 🧠 Why I Built This

I created this project while learning Python, to explore:
- How to automate real-world tasks with Python
- How to use PowerPoint COM API with `comtypes`
- How to build desktop apps with `tkinter`
- How to handle file dialogs, threading, and UI updates

If you’re also learning Python — this project is a great starting point for you! 🚀
